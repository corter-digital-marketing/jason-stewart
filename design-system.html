Rule of thumb: When deciding between two spacing values, choose the larger one. Sections breathe at 96–192px vertical padding. Element gaps live at 24–48px. Tight micro-spacing stays at 8–16px.

Motion Principles

Timing

300ms — hover state micro-interactions
400ms — element transitions
600ms — image reveals, page transitions
800ms — scroll-triggered fades

Easing

Standard: cubic-bezier(0.4, 0, 0.2, 1)
Reveal: cubic-bezier(0.16, 1, 0.3, 1)

Animate: transform and opacity only

Accessibility

Focused Nav Link

Focus rings: 2px champagne (#B8974A), 3px offset. Visible on all keyboard-navigable elements. Background to text contrast: charcoal on ivory = 12.7:1 (AAA). Charcoal.muted on ivory = 5.8:1 (AA).
